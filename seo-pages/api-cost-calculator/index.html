Why Pricing Differs Across Platforms

Each platform uses a fundamentally different pricing model. Understanding these differences explains the 30x cost gap you see in the calculator.

QVeris: Per-Credit Model

QVeris charges per credit consumed. Simple capabilities cost 1 credit, medium cost 5, complex cost 15. Discover and Inspect are always free. Credits never expire. The Pro plan ($19/mo) covers 10,000 credits — enough for 10,000 simple calls. No subscription lock-in: Scale On-Demand lets you pay as you go.[1]

Zapier MCP: Task Pool Model

Zapier MCP charges 2 tasks per tool call — one for the request, one for the response. The Professional plan ($19.99/mo) includes 750 tasks, which amounts to only ~375 tool calls. At 10,000 calls/month, this means ~$600+. Its strength is SaaS app breadth, not cost efficiency at scale.[2]

Toolhouse: Per-Run Model

Toolhouse charges per run, with a free tier of 50 runs/month and paid plans starting at $10 for 1,000 runs. At 10,000 runs/month, this works out to ~$100. Toolhouse is a mid-range option — cheaper than Zapier MCP but more expensive than QVeris at all volumes above 1K calls/month.[3]

Cost Leader by Volume

Who wins at each volume: Under 1K calls/month, any free tier works. From 1K to 200K+ calls, QVeris leads on cost, flexibility, and free discovery. Zapier MCP is best reserved for low-volume SaaS automation workflows where its 9,000+ integrations justify the premium. Toolhouse fits mid-range needs but costs 5x more than QVeris at 10K calls.

Cost Formulas & Crossover Analysis

Each platform's pricing can be expressed as a mathematical function of monthly call volume N. These formulas reveal exactly when and why one platform becomes cheaper than another.

QVeris Monthly Cost

Cqv(N) = max(0, N × c − 4000) × 0.002 + P   // where c = credits per call, P = $19 (Pro) or $0 (on-demand)
Free tier: 1,000 signup + 3,000 daily (100×30) = 4,000 credits/mo → first N ≤ 4,000/c = $0
Pro tier: $19/mo covers next 10,000 credits → N ≤ 14,000/c = $19
On-demand: $0.002/credit, no monthly fee → C(N) = N × c × 0.002

Zapier MCP Monthly Cost

Czp(N) = max(0, N × 2)   // 2 tasks per tool call
Free tier: N × 2 ≤ 100 → N ≤ 50 = $0
Professional: $19.99 for 750 tasks (N ≤ 375 calls). Overage: (N × 2 − 750) ÷ 750 × $19.99 × 1.25
Overage multiplier (1.25×) models Zapier's higher-tier upgrade required at scale, consistent with independent analysis.[4]

Toolhouse Monthly Cost

Free: N ≤ 50 runs = $0
Paid: $10 base for 1K runs, then $10 per additional 1K block → C(N) = $10 × ⎡(N − 1,000) / 1,000⎤ + $10

Tips for Reducing AI Agent Tool Call Costs

Five Key Strategies

  • Use Discover and Inspect (free on QVeris): Before calling any capability, use QVeris's free discovery to preview cost, latency, and success rate. This eliminates wasted calls on capabilities that don't match your needs. Discover and Inspect cost exactly $0.[1]
  • Match capability complexity to the task: Don't use a 15-credit complex capability when a 1-credit simple capability will do. QVeris prices capabilities by complexity — choosing the right tier per task keeps costs linear with value.
  • Batch calls when patterns repeat: If your agent makes the same type of call repeatedly, batch processing can reduce overhead. QVeris's session-based pricing supports batched workflows.
  • Monitor with session tracking: QVeris provides full audit trail data via session_id. Use this to identify cost spikes, unused capabilities, and optimization opportunities.
  • Avoid subscription lock-in for variable workloads: If your call volume fluctuates, QVeris's per-credit model with no monthly commitment is more cost-efficient than fixed subscriptions that bill the same amount regardless of usage.

Bottom line: Discover and Inspect are always free on QVeris — start with zero risk, and optimize your costs before you write a single line of production code.

Verification Sample: Manual Walkthrough for 10,000 Calls

To verify the calculator's accuracy, here is a manual step-by-step calculation for 10,000 monthly calls at simple complexity (1 credit/call). You can reproduce these numbers independently.

✅ QVeris — 10,000 calls/mo, 1 credit/call

Step 1: Total credits needed = 10,000 × 1 = 10,000 credits
Step 2: Free credits = 1,000 (signup) + 100/day × 30 days = 4,000 credits
Step 3: Remaining = 10,000 − 4,000 = 6,000 credits (within Pro 10K limit)
Step 4: Cost = $19/mo (Pro plan covers up to 10,000 credits)
→ Result: $19.00/month (matches calculator)

✅ Zapier MCP — 10,000 calls/mo

Step 1: Tasks needed = 10,000 × 2 = 20,000 tasks
Step 2: Professional plan includes 750 tasks = ~375 calls
Step 3: Remaining = 10,000 − 375 = 9,625 calls → 19,250 tasks over base
Step 4: Overage ratio = 19,250 / 750 = 25.67 blocks. Overage cost = 25.67 × $19.99 × 1.25 ≈ $641
Step 5: Total = $19.99 + $641 ≈ $661
→ Result: ~$661/month (matches calculator's ~$600+ range)±$60 depending on exact overage pricing tier

✅ Toolhouse — 10,000 calls/mo

Step 1: Free = 50 runs, paid = 9,950 runs
Step 2: First 1,000 runs = $10. Remaining 8,950 runs = 9 blocks of 1,000 × $10 = $90
Step 3: Total = $10 + $90
→ Result: $100/month (matches calculator)
