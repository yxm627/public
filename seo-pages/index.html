Technical Architecture

One integration, any finance data source. Your AI agent calls a single QVeris endpoint. QVeris's capability routing layer selects the optimal provider based on availability, rate limits, and coverage — then normalizes the response into a consistent JSON format. Built on the MCP (Model Context Protocol), with CLI, REST API, and Python SDK interfaces. Capability discovery via qveris discover "stocks" --json returns available providers and their current status. Automatic fallback: if one provider hits rate limits, QVeris routes to another transparently.

Frequently Asked Questions

What is QVeris and how does it work?
QVeris is an AI-agent capability router that gives AI agents unified access to 10,000+ finance capabilities through one endpoint. Instead of integrating separately with each data provider, agents call QVeris once and get routed to the right provider — stocks, options, crypto, macro data, or KYC — with automatic fallback and normalized responses.
Does QVeris have a free tier?
Yes. Discover and Inspect capabilities are completely free. You pay only for the calls your agents make — pay-per-call pricing with no monthly minimums. This means you can build and test your AI agent integration at zero cost and scale up when ready.
How does QVeris compare to Polygon.io or Alpha Vantage?
Polygon.io starts at $99/mo for stock data. Alpha Vantage starts at $49.99/mo. QVeris offers free Discover & Inspect with pay-per-call pricing across 10,000+ capabilities — including stocks, options, crypto, macro data, and KYC. QVeris also provides automatic fallback across providers, normalized response formats, and a single integration point.
What finance capabilities does QVeris support?
QVeris supports 138 finance-specific capabilities including: real-time and historical stock prices, options chains, cryptocurrency prices, forex rates, macro economic indicators, KYC/identity verification, financial news with sentiment scoring, and corporate actions data. All accessible through one MCP, CLI, or REST API endpoint.
Is QVeris secure for production use?
Yes. QVeris employs encryption in transit (TLS 1.3) and at rest, with API-key based authentication. Each request is logged for audit trails. QVeris does not store your API credentials — your keys remain on your infrastructure. See our Security page and Terms of Service for full details.
