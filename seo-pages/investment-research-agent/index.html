Getting Started: Build Your First Investment Research Agent

Here's how to build a simple AI investment research agent in Python using QVeris. This agent discovers and fetches S&P 500 market data with about 20 lines of code.

Prerequisites

  • Python 3.9+
  • QVeris API Key (free from qveris.ai)
  • QVeris Python SDK: pip install qveris-sdk

Code Example

# Step 1: Initialize the QVeris client
from qveris import QVerisClient
client = QVerisClient(api_key="your-api-key")

# Step 2: Discover financial capabilities
capabilities = client.discover(
    query="S&P 500 current market data top movers"
)
# Returns: ranked capabilities with cost (~1 credit), 
# latency (~180ms), and success rate (99.8%)

# Step 3: Inspect the best match
sp500_cap = capabilities[0]
inspection = client.inspect(sp500_cap.id)
# Preview: schema, cost, latency, reliability — always free

# Step 4: Call and get structured data
result = client.call(sp500_cap.id, params={
    "symbols": ["SPY", "QQQ", "IWM"],
    "fields": ["price", "change", "volume"]
})
# Returns: structured JSON with full audit trail
print(result.data)
